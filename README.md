# Don Bosco Tech Africa (DBTA) — Official Platform

Modern, high-performance continental digital platform for Don Bosco Tech Africa (DBTA), coordinating 119 Salesian Technical and Vocational Education and Training (TVET) centres across 35 countries in Africa and Madagascar.

## Key Features

- **Continental Network Explorer**: Detailed coverage of 119 TVET institutions, 35 national territories, and 15 Salesian Provinces (P-TVET).
- **Thematic Workstreams**: Comprehensive documentation and resources for Quality TVET & QMS, Employability & JSO, Green TVET & Solar PV, Digital Skills, Recognition of Prior Learning (RPL), and Institutional Capacity Building.
- **Editorial Design System**: Clean, accessible, light institutional theme optimized for international education standards, generous typography, and minimal cognitive load.
- **Knowledge Hub & Toolkits**: Access to research reports, curriculum manuals, tracer study documents, and strategic roadmaps.
- **Digital Services Integration**: Gateways to DBTVET Management, Digital Library, Inserjeune tracer platform, and Secretariat tools.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or `http://localhost:3001` if port 3000 is occupied).

## Production Build

```bash
npm run build
npm run start
```
